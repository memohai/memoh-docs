# Plugins

Plugins are installed bundles from Supermarket that can add capabilities to a bot. A plugin can expose MCP resources, skills, or other packaged setup metadata depending on how it was published.

---

## Bot Plugin Management

Open a bot's **Detail Page** and go to the **Plugins** tab to manage installed plugins for that bot.

From this tab you can:

- view installed plugin status
- see whether a plugin needs authentication
- inspect exposed resources
- start or complete authentication when required
- uninstall a plugin from the bot
- purge plugin state when you want a clean reinstall

The Plugins tab shows bot-level plugin state. Installing new bundles still starts from Supermarket.

---

## How Plugins Relate To Other Features

- **Supermarket** is where curated bundles are discovered and installed.
- **Skills** are reusable Markdown behavior modules that a plugin can provide.
- **MCP** connections expose external tools and resources; plugins can package MCP-related setup.
