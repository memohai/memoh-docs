# Containerd + Kata (Removed)

<Callout type="danger">
  **Removed feature**

  Kata Containers support has been removed from Memoh. Current versions run workspace containers with standard containerd runtimes only, and the `[containerd].runtime_type` Kata setting, the `server-kata` image target, and the Kata compose overlays no longer exist.
</Callout>

If you were running an older Memoh version with Kata workspaces:

- Switch the deployment back to the standard `containerd` backend before upgrading. Workspace data itself lives in containerd snapshots and the data volume, not in the Kata runtime, so bots keep their files.
- Remove Kata-specific compose overrides (`/dev/kvm` mounts, Kata shim mounts, `BRIDGE_TCP_ADDR` bridge settings) from your stack.

For current backend options, see [Workspace Backends](/self-hosted/workspace-backends).
