# 插件

插件是从超市安装的能力包，可以给机器人增加功能。一个插件可以暴露 MCP 资源、技能，或其它打包好的设置元数据，具体取决于它发布时包含了什么。

---

## 机器人插件管理

打开机器人 **详情页**，进入 **Plugins** tab，就能管理这个机器人已安装的插件。

这里可以：

- 查看已安装插件状态
- 查看插件是否需要授权
- 检查插件暴露的资源
- 在需要时开始或完成授权
- 从机器人上卸载插件
- 清理插件状态，方便重新安装

Plugins tab 展示的是机器人级插件状态。安装新的能力包仍然从超市开始。

---

## 插件和其它功能的关系

- **超市** 用来发现和安装精选能力包。
- **技能** 是可复用的 Markdown 行为模块，插件可以提供技能。
- **MCP** 连接外部工具和资源，插件可以打包 MCP 相关设置。
